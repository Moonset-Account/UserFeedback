# 对象存储配额模块（quota_store）

跨租户块级去重的对象存储配额模块。纯标准库实现，开发验证环境为 Python 3.11.6。

## 功能

- **块级去重**：同一个块在同一租户的全部对象里只收费一次；在存储池里也只占一份物理空间。
- **事务式批量操作**：一笔 `apply` 中可新增、替换、删除多个对象，也可通过 `copy_from`
  让目标租户整体复制另一租户**在操作开始时**的对象清单快照。
- **一次结算**：每笔操作按最终引用关系结算各受影响租户配额与全池容量；任一超限即整笔
  拒绝，抛出 `QuotaExceededError`（携带所有超限方与差额），存储状态完全不变，
  所有对象仍可按原清单读取。
- **延迟释放**：物理块只在最后一个引用被移走时释放。
- **重新计数报告**：每次操作返回实际重新计数的块编号——只涉及本次被改对象的旧清单与
  新清单中的块，未触碰的对象不参与。

## 公开 API（`quota_store.py`）

### `ObjectStore(pool_capacity, blocks=None)`

- `pool_capacity`：全池物理容量（字节，非负整数）。
- `blocks`：可选初始块目录 `{块编号: 字节数}`。

方法：

| 方法 | 说明 |
| --- | --- |
| `register_block(block_id, size)` | 登记块及字节数（非负整数）。仍被引用的块不允许改变字节数。 |
| `block_size(block_id)` | 查询块字节数。 |
| `set_quota(tenant, quota)` | 创建/更新租户；`quota=None` 表示不限量。操作前必须先建租户。 |
| `quota(tenant)` / `usage(tenant)` | 查询租户配额 / 当前计费用量（租户内去重后）。 |
| `pool_used` / `pool_capacity` | 全池当前物理占用 / 容量（属性）。 |
| `live_blocks()` | 当前仍占物理空间的块编号集合。 |
| `read(tenant, obj)` | 按写入时的原清单读取（保留顺序与重复项）。 |
| `list_objects(tenant)` | 租户对象清单快照 `{对象: [块, ...]}`。 |
| `put(tenant, obj, blocks)` / `delete(tenant, obj)` | 单对象便捷操作（各为一笔独立操作）。删除不存在的对象是无操作。 |
| `apply(changes=None, *, copy_from=None)` | 事务式批量操作，返回 `OperationReport`。 |

### `apply` 参数

- `changes`：`{租户: {对象: 新块清单 或 None}}`。清单用于新增/替换；`None` 表示删除。
- `copy_from`：可选 `(源租户, 目标租户)`。目标租户的对象清单先整体替换为源租户在
  **操作开始时**的快照，`changes` 中对目标租户的修改随后叠加。源与目标不能相同。

### 返回与异常

- `OperationReport`：`recounted_blocks`（本次实际重新计数的块编号，排序后）、
  `tenant_usage`（受影响租户结算后用量）、`pool_used`、`pool_capacity`。
- `QuotaExceededError`：属性 `violations` 为 `Violation` 元组；每个 `Violation`
  含 `scope`（`"tenant"`/`"pool"`）、`name`、`used`、`limit` 与 `deficit`（差额）。
  抛出时状态不变。租户配额与池容量超限可在同一笔中一起报告。
- `KeyError`：引用未登记的块、操作未知租户、读取不存在的对象。
- `ValueError`：负的容量/字节数/配额、源目标相同的复制、改变仍被引用块的字节数。

## 语义要点

- 计费按**集合**去重：清单中重复出现的块只计一次；但 `read` 按原清单返回。
- 结算校验的是**本笔操作涉及的租户**的最终用量与全池最终占用；任一超限整笔回滚。
- 复制语义为整体替换目标租户清单，快照取自操作开始时刻，同笔操作内对源租户的
  修改不影响复制内容。

## 复现步骤

```bash
# 需要 Python 3.11（开发验证版本 3.11.6），无第三方依赖
cd <工作区根目录>
python3 -m unittest discover -s tests -t .   # 或：python3 -m unittest
```

## 验证范围

`tests/test_quota_store.py` 共 27 个用例，全部基于真实功能执行（无预置输出）：

- **正常场景**：租户内跨对象去重、清单内重复块去重、跨租户共享块全池只占一份、
  替换对象后的用量更新、读取保真。
- **边界场景**：零字节块与空清单、零容量池、删除不存在的对象、未知块/未知租户拒绝、
  负数参数拒绝、不限量租户、物理块在最后引用移除时才释放。
- **批量与复制**：一笔操作内新增+替换+删除、复制快照取自操作开始时、复制整体替换
  目标清单并释放旧块、复制后叠加修改、源目标相同拒绝。
- **超限结算**：租户超限与池超限分别报告超限方与差额、共享块不触发池超限、
  跨租户批量失败整体回滚且原对象仍可按原清单读取、多种超限同时报告、
  **两个刚好用满的租户在同一笔操作中互换等大块内容成功**（题面示例）。
- **重新计数报告**：只改一个对象时只涉及其旧清单与新清单里的块；删除只涉及被删清单；
  批量操作中未触碰对象的块不参与。
- **交错场景**：多租户交替增删改并穿插被拒绝的操作，验证最终引用关系、用量与
  物理占用一致，且失败操作之后存储继续正常工作。
