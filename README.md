# 稀疏快照克隆规划与发布模块

灾备平台场景：把源租户的稀疏磁盘快照安全克隆给新租户。模块基于固定版本的
父子快照链、块覆盖区间、数据分类和逐区间净化回执，先按快照层解析每段最终
可见来源，再按目标租户的发布权限做出发布决策，最后在同一提交动作内完成
父链版本终检与可见性切换。

## 模块与入口

- Go 版本：Go 1.20（`go.mod` 声明，本地以 go1.20.2 验证），仅依赖标准库。
- 包路径：`cloneplanner/cloneplan`
  - `types.go`：领域类型与哨兵错误（区间、快照、块记录、回执、规划结果、
    发布结果、决策枚举）。
  - `planner.go`：`Store.BuildPlan` 规划器。
  - `store.go`：`Store` 快照注册表、草稿暂存、原子提交与版本轮转。

### 实际入口

| 入口 | 作用 |
| --- | --- |
| `NewStore()` | 创建并发安全的注册表/发布存储 |
| `Store.Register(Snapshot)` | 注册不可变固定版本快照层；校验父链存在、无环、块记录区间不重叠 |
| `Store.BuildPlan(PlanRequest)` | 父链解析 + 回执交叉校验 + 发布策略，产出 `ClonePlan` |
| `Store.Stage(*ClonePlan)` | 将可发布计划存为不可见草稿；被阻止的计划拒绝暂存 |
| `Store.Commit(planID)` | 同一锁内重走父链做最终版本核对，通过才原子可见；失败即丢弃草稿 |
| `Store.GetPublished / ListPublished / GetDraft / Get` | 只读查询，均返回防御性拷贝 |
| `Store.RetireVersion(SnapshotRef)` | 固定版本轮转（测试/运维入口），使依赖该版本的草稿提交失败 |

## 实现的语义与交叉约束

1. **按层确定最终可见来源**：从叶快照向根逐层解析；本层有块记录则该层生效，
   本层无记录的空洞继续查祖先；整条链都未覆盖的区间终止为稀疏空洞零。
2. **显式清零语义保留**：`BlockRecord.Zero=true` 的显式零层立即终止解析并
   遮蔽祖先数据；稀疏空洞与显式零都发布为零内容，但通过 `ExplicitZero`
   与 `Reason` 区分语义。
3. **发布权限**：只发布目标租户拥有（`OwnerTenant` 匹配）或持有有效净化
   回执的区间。
4. **可丢弃敏感数据**：`Discardable=true` 的敏感数据在缺少回执时清零；
   不可丢弃的敏感数据缺回执则阻止发布；非敏感且非自有数据缺回执同样阻止。
5. **回执必须对应实际生效的块版本**：回执版本与解析出的有效版本不一致即
   `ErrReceiptStaleVersion`；回执跨数据段与显式零/稀疏空洞即
   `ErrReceiptCoversZero`；回执跨两个有效版本同样拒绝。一个区间可由多张
   回执共同覆盖（测试中 `[10,20)` 由两张回执覆盖），规划时按回执边界切段，
   逐子段做统一决策。
6. **同提交终检、失败草稿不可见**：`Commit` 从实时注册表重走父链，核对
   固定版本链与逐段有效块版本；任何不一致返回 `ErrChainMismatch` 并删除
   草稿，`ListPublished` 不出现该克隆，源快照保持可读、可继续注册与发布。
7. **不可变性**：注册的快照与已发布克隆只通过防御性拷贝对外暴露，调用方
   改动返回值不影响内部状态。

## 验证范围

测试文件：`cloneplan/store_test.go`，使用 Go 内置 `testing` 与真实断言
（无占位断言），合成三层父子快照夹具（root base v1 → mid v2 → head v3），
覆盖：

- **可接受结果**：全量克隆规划、多回执覆盖同一区间、显式零/祖先回退/
  稀疏空洞解析、暂存→原子提交→可见与提交序号。
- **应被阻止/拒绝的结果**：缺回执的不可丢弃敏感数据阻止发布且无法暂存；
  过期回执版本、指向被覆盖祖先版本的回执拒绝；回执跨清零段、跨版本段、
  越出克隆区间拒绝；租户不匹配、重复回执 ID、未知快照、非法区间等结构
  校验；同一数据段仅部分回执时未覆盖子段阻止。
- **边界/交错场景**：部分克隆区间、段边界上的回执切段、显式零与数据段
  交错、空洞跨层回退、16 路并发提交的原子性与序号唯一性。
- **提交失败原子性**：轮转移除祖先版本后提交失败，草稿与可见集均无残留，
  源快照仍可用，独立链仍可正常发布。
- **防御性拷贝**：注册入参与查询返回值被外部篡改时内部状态不变。
