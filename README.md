# Offline Write-Plan Validator

离线写入计划校验器：插件安装器在复制任何文件**之前**，用它确认归档清单里的
每个条目都属于自己的隔离根目录。纯函数、零运行时依赖、不接触真实文件系统。

## 输入

1. **已解析归档清单**（合成数据）：`{ type, entryPath, contents? }` 数组。
2. **安装目标的虚拟文件树**：扁平 map，键为 `/` 分隔的相对路径，
   值为 `{ type: 'file' | 'directory' }`（普通对象或 `Map` 均可）。

## 声明的比较规则（`src/path-rules.js`）

| 规则 | 取值 | 说明 |
| --- | --- | --- |
| 路径分隔符 | `'/'` | 只承认正斜杠；反斜杠一律拒绝（`PATH_CONTAINS_BACKSLASH`），杜绝 Windows 风格歧义 |
| Unicode 规范化 | `'NFC'` | 每个路径分量先做 NFC 再比较，NFD/NFC 同名必然碰撞；计划中保留 NFC 原拼写 |
| 大小写比较 | `'sensitive'`（默认）/ `'insensitive'` | 不敏感时用与区域无关的 Unicode 简单大写映射折叠 |

## 校验阶段（全部通过才出计划，任一失败即整体拒绝）

1. **类型闸门**：只允许普通 `file` 与 `directory`；symlink、hardlink、设备文件等
   一律 `UNSUPPORTED_ENTRY_TYPE` 明确拒绝。
2. **路径结构检查**：空路径、NUL、反斜杠、绝对路径（含 `C:/`、UNC）、空分量、
   `.` 与 `..` 分量分别给出独立错误码。
3. **根目录归属**：对计算出的目标再显式执行 `isInsideRoot()` 断言——纵深防御，
   安全边界不依赖上游解析的正确性。
4. **批内碰撞**：规范化（含大小写规则）后同键 → `DUPLICATE_ENTRY`；
   文件路径之下不得再有子条目 → `FILE_ANCESTOR_CONFLICT`。
5. **目标树冲突**：同路径类型不一致 → `TARGET_TYPE_CONFLICT`；
   现有文件挡住子路径 → `TARGET_ANCESTOR_IS_FILE`。同类型兼容（目录合并、
   同路径文件降级为 `noop`，不做静默覆盖）。

## 确定性计划

- 先补齐所有条目的隐式父目录，再统一排序；
- 目录在前、文件在后，各自按比较键升序；
- 动作只有 `mkdir` / `writeFile` / `noop`；
- 同一输入（含乱序输入）重复计算得到深相等的计划。

## 内存写入桩（`src/memory-writer.js`）

- 先在树的**克隆**上演练全部操作，全部成功才一次性提交；
- 任何一步失败，真实树与调用日志保持原样——被拒绝的批次不留部分变更；
- 写入桩自身重新执行结构检查与根归属检查，伪造的计划也无法逃逸。

## 运行测试

```bash
node --test
```

覆盖：正常嵌套目录、NFC/NFD 规范化重名、大小写折叠、目标已有同名目录、
文件/目录冲突、链接等非法条目类型、混合有效/无效批次的原子拒绝、
写入桩回滚、以及合法计划重算稳定性（共 20 个用例）。
