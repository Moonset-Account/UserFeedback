# 子进程接口回归套件

批处理服务子进程接口改造后的回归测试。通过内存适配器（`src/adapter.js`）模拟调用，
记录每次调用的**程序标识、参数数组、批准的环境变量**，不真正拉起子进程。

## 运行

```bash
npm test          # 等价于 node test/regression.js
```

## 结构

- `tasks/*.json` — 本地任务记录：工作目录、可执行程序标识、参数（含空串/缺失值用例）、环境变量
- `config/policy.json` — 环境变量策略（批准清单）、不可变参数、允许的工作目录根
- `src/invoker.js` — 调用方：校验策略 → 构造 argv/env → 调用适配器 → 写审计日志
- `src/adapter.js` — 内存适配器：按引用捕获 env，用于检测跨调用共享
- `src/audit.js` — 追加式审计日志（JSON Lines）

## 覆盖点

| 测试 | 类别 |
|---|---|
| 含空格的参数作为单个数组元素传入 | arg-boundary |
| 空字符串与缺失值（null）可区分 | arg-boundary |
| 不可变参数固定在最前、任务不得覆盖 | other |
| 工作目录必须落在允许的根目录内 | other |
| 只下发批准变量，不继承 process.env，未批准键被过滤 | env-inheritance |
| 重试不共享前一次任务的环境对象 | env-inheritance |
| 适配器抛错时审计日志只含任务编号和字段名 | other |

## 退出码（位掩码，供 CI 区分失败类别）

| 码 | 含义 |
|---|---|
| 0 | 全部通过 |
| 1 | 其他失败（策略 / 审计 / 基础设施） |
| 2 | 参数边界丢失 |
| 4 | 环境变量继承异常 |

组合按位或，例如 `6` = 参数边界 + 环境继承同时失败。
