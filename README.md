# 边缘节点范围缓存（edge-range-cache）

面向视频边缘节点的本地字节范围缓存基础设施组件。节点常常只缓存对象的一部分：
写入的局部响应带有**总长**和**闭区间** `[start, end]`，查询按
`(资源路径, 内容编码, ETag, 字节范围)` 返回已缓存字节与仍需回源的连续缺口。

本组件仅做本地功能实现与单元测试，不包含任何网络访问、真实目标探测或负载。

## 运行环境与入口

- 运行时：Node.js v24.15.0（ESM，`"type": "module"`，无第三方依赖）
- 库入口：`src/range-cache.js`
  - 命名导出：`RangeCache`、`parseETag`
- 测试入口：`tests/range-cache.test.mjs`（基于 `node:test`，全部为真实断言）
- 运行方式：

```bash
node --test tests/*.test.mjs
# 或
npm test
```

## API

### `new RangeCache()`

### `cache.put(path, data, options)`

写入一个局部响应（或整包响应）。`data` 支持 `Buffer` / `Uint8Array` / 字符串。

| 选项 | 说明 |
| --- | --- |
| `etag` | ETag 头值，如 `'"v1"'` 或 `'W/"t1"'`（必填） |
| `encoding` | 内容编码；省略 / `null` / `'identity'` 均表示原版（不区分大小写） |
| `totalLength` | 该表示的完整字节总长（正整数，必填） |
| `start` / `end` | `data` 对应的闭区间；整包写入时可省略，默认 `[0, totalLength-1]` |
| `trusted` | 仅与整包数据一起使用，表示可信整包响应，可重建已失效的表示 |

返回 `{ status, reason?, validator }`，`status` 取值：

- `stored`：写入了新字节（允许伴随相同字节的重叠）
- `merged`：纯冗余写入，重叠字节全部相同
- `invalidated`：本次写入触发表示失效（总长冲突或重叠字节冲突）
- `rejected-invalid`：表示已失效，普通片段被拒绝，等待可信整包重建
- `rebuilt`：可信整包完成重建

### `cache.query(path, options)`

查询闭区间 `{ start, end }`，需带 `etag`、可选 `encoding`。返回：

```js
{
  hit: boolean,        // 整个请求区间是否已被缓存覆盖
  validator: 'strong' | 'weak',
  encoding, etag, totalLength,
  hits: [{ start, end }, ...],  // 命中的连续区间（按请求顺序）
  gaps: [{ start, end }, ...],  // 需回源的连续缺口
  data: Buffer | null,          // 命中字节按请求范围顺序拼接的结果
  reason?: string,
}
```

### `cache.getState(path, { etag, encoding })`

查看强标记表示的覆盖计数、是否完整、是否失效及失效原因（主要用于核验）。

## 缓存语义（与题面约束对应）

1. **强标记拼接**：相同路径、内容编码与强 ETag 的片段共享同一稀疏字节空间，
   相邻片段可拼接；重叠字节必须逐字节相同。
2. **冲突失效**：同一强标记下出现总长不一致，或重叠位置字节不一致，该表示立即
   失效：丢弃已缓存负载、拒绝后续普通片段，查询不再命中，直到一次
   `trusted: true` 的整包响应重建。
3. **弱标记隔离**：`W/` 开头的弱 ETag 片段各自独立保存、互不拼接。仅当**单个
   片段完整覆盖**请求区间时才命中；多份可用时取最新入库的一份（入库序号判定）。
4. **编码隔离**：同一路径的压缩版与原版是不同表示，交错填充互不污染；任一表示
   失效不影响另一表示。`hits` 中的字节严格来自所查询编码的表示，按请求范围顺序
   拼接即可还原该表示的原字节。
5. **ETag 隔离**：不同 ETag（无论强弱）绝不拼接。
6. **边界**：闭区间端点包含两端；支持单字节区间；超出总长的请求整体不命中并给出
   `reason`；长度与区间不符、非法 ETag 等输入在修改状态前抛错。

## 验证范围（tests/range-cache.test.mjs，11 个用例）

### 可接受结果
- 强标记相邻 + 重叠片段拼接，最终整段按请求范围还原原始字节
- 相同重叠字节的纯冗余写入合并（`merged`）
- 可信整包响应重建失效表示后立即全量命中
- 弱标记单片完整覆盖命中（含恰好落在片段边界的请求）
- 压缩版 / 原版交错写入后各自独立命中并还原字节
- 不同强 ETag 的同路径表示互不拼接

### 应被阻止 / 拒绝的结果
- 重叠字节冲突触发失效，失效后查询不返回任何缓存字节
- 总长冲突触发失效
- 失效表示拒绝普通片段；不可信整包同样被拒绝
- 弱标记相邻片段不拼接，跨片段请求不命中
- 一种编码失效不影响另一编码；超总长请求不命中

### 边界与交错场景
- 单字节区间、首尾边界、命中区间被中间缺口交替切分（多段 `hits`/`gaps`）
- 压缩与原版写入交错、查询交错，且命中结果可直接拼回原字节
- 弱标记多份完整片段取最新入库者
- 非法区间 / 长度不匹配 / 畸形 ETag 在状态变更前抛错（写入后状态仍为空）
