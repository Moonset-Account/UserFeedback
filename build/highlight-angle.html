设备错误诊断 / Device Error Diagnostics

页面内容一律按文本显示；搜索仅做高亮，不改变字符。文档链接仅允许 HTTPS 且主机属于白名单：docs.example.com；含凭据的链接与白名单外链接按普通文本展示。

渲染安全 / Rendering Safety

rec-html-angle-brackets

设备返回：<error code="E42">缓冲区溢出 & 重试</error>；请检查 <config> 与 'quotes'。

<response status="500">
  <message>unsafe <b>markup</b> & ampersand</message>
  <raw>a < b && c > d</raw>
</response>

文档 错误码说明 <E42> & 处理建议 https://docs.example.com/errors/E42?ref=diagnostics&lang=zh

文档链接策略 / Link Policy

rec-link-userinfo

该链接带凭据，必须降级为普通文本，但本记录和相邻记录仍需可见。

url = https://user:pass@docs.example.com/private

文档链接不可用 https://user:pass@docs.example.com/private 包含凭据（用户名或密码）

rec-link-evil-suffix

后缀伪造域名 docs.example.com.evil.test 不在白名单内。

文档链接不可用 https://docs.example.com.evil.test/errors/E42 主机不在文档链接白名单内

rec-link-http

明文 HTTP 地址不允许。

文档链接不可用 http://docs.example.com/errors/E42 不是 HTTPS 地址

rec-link-ip-literal

IP 直连地址不在白名单内。

文档链接不可用 https://192.0.2.10/errors/E42 主机不在文档链接白名单内

rec-link-tab-bypass

地址中嵌入 TAB 试图混淆主机名解析。

文档链接不可用 https://docs.example.com .evil.test/errors/E42 包含空白、控制或不可见格式字符

rec-no-doc

没有文档链接的记录也必须完整显示。

status=degraded
retry_after=30s

rec-link-uppercase-host

主机名大小写不敏感，大写形式仍应命中白名单。

文档 大写主机 https://DOCS.EXAMPLE.COM/errors/E42

rec-link-trailing-dot

带根点的主机名按规范化后的主机名验证。

文档 根点主机 https://docs.example.com./errors/E42
